# buckets-of-love
A community appreciation platform designed to make sharing gratitude easy and meaningful. Built to facilitate 1-on-1 and Group 'Buckets' of compliments for virtual events and team building.

# 🪣 Buckets of Love
**Elevating Digital Connection through Intentional Appreciation**

### 🎯 The Problem
Digital communication in remote teams and virtual events often lacks "emotional warmth." It’s easy to send a task, but hard to send a genuine, meaningful compliment in a way that feels special.

### 💡 The Solution
"Buckets of Love" is a vibe-coded MVP that allows users to create personalized "appreciation links." 

**Key Features:**
- **Personalized Links:** Unique URLs for users to collect and store private compliments.
- **Group Buckets:** A collaborative feature for virtual events where participants can add compliments for specific teammates in real-time.
- **Presenter Mode:** (In Development) A high-fidelity UI for screen-sharing compliments during live meetings.

### 🛠 Tech Stack & Workflow
- **Frontend:** React + Tailwind CSS (Mobile-First Design)
- **Deployment:** CI/CD via Vercel and GitHub
- **Process:** Built using an iterative "vibe coding" workflow, moving from a 1-hour prototype to a persistent database-driven application.
